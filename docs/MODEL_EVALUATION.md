# Model Evaluation

## Protocol
- Metrics with explicit denominators: vehicle detection recall, plate detection recall, OCR exact-match, full-plate read rate, CER, false positive rate, duplicate rate, needs-review rate, image-quality failure rate.
- Splits: daylight / dusk / night / rain / glare.
- Data: synthetic or licensed fixtures in repo; user recordings only in git-ignored `datasets/private/`.
- Pilot (GO/NO-GO) first, larger evaluation after.
